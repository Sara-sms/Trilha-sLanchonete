TRILHA`S LANCHES
Aluna: Sara Machado Silva
Trilha: Desenvolvimento Mobile


Sobre o projeto:
Se trata da simulação simples de uma lanchonete feita utilizando html, css e javaScript.

Sobre a lanchonete:
É uma lanchonete fast-food. Seus principais produtos são:
Hambúrguer Completo - 25,00;
X-Salada - 18,00
Batata-Frita - 12,00
Refrigerante em lata: 8,00

Como execuatar:
1 - Baixe o repositório.
2 - Abra o index.html no navegador.
3 - Siga o passo a passo de uso do site.
